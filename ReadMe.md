# AI Meal Scanner

A full-stack mobile and web application that uses AI to analyze food images and extract nutritional data.

## Tech Stack
- **Frontend:** React Native (Expo), TypeScript
- **Backend:** Node.js, Express
- **AI:** Google Gemini API
